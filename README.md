# Gran Turismo 5 & 6 Cheats and Patches

A repository containing a collection of cheats and memory patches for Gran Turismo 5 and 6. 

🎥 **[Video showcase of the patch in action](https://www.youtube.com/watch?v=ndvbrKmkF5Q)**

---

## Usage on RPCS3 (Emulator)

### Standard Method (.yml patches)
1. Download the provided `.yml` patch file.
2. Move the file into the `patches` folder located inside your RPCS3 directory.
3. Launch RPCS3, manage your game patches, and enable the cheats.

### Alternative Method 
If the standard `.yml` memory patch doesn't work for any reason, you can use the provided `.txt` cheat codes as an alternative.

## Usage on PS3 (Requires Custom Firmware - CFW)

To use these cheats on a real PS3 console, download the `.ncl` tables provided in this repository. You can use them with **NetCheat** or **ArtemisPS3**. 

Below is the detailed setup guide for using these codes with **ArtemisPS3** and **webMAN MOD**.

### Prerequisites
* A PS3 running Custom Firmware (CFW).
* **webMAN MOD** installed.
* **ArtemisPS3** installed.

### Step-by-Step Guide


**1. Initial Setup**
* Go to `/setup.ps3` (webMAN MOD settings), check the **Artemis** option, and save the settings.
* Install and launch **ArtemisPS3** from the XMB.
* Configure ArtemisPS3 to use webMAN MOD by going into the options and choosing "webMAN MOD" as your plugin version.

**2. Installing the Cheat Files (.ncl)**
Choose between installing the `.ncl` files on a USB flash drive or directly into the Artemis installation directory on your PS3.

* **Method A: USB Flash Drive**
  1. Create a new folder on the root of your USB drive and name it `USERLIST`.
  2. Place your downloaded `.ncl` files inside this folder.
  3. Insert the USB drive into the **right-most** USB slot of your PS3.

* **Method B: Internal HDD (FTP / multiMAN)**
  1. Launch an FTP server on your PS3 (e.g., via multiMAN) or use a file manager.
  2. Navigate to the following path: `/dev_hdd0/game/ARTPS3001/USRDIR/USERLIST/`
  3. Copy the `.ncl` files into this folder.

**3. Loading the Cheats**
* Launch **ArtemisPS3** from the XMB (make sure the USB is inserted if you used Method A).
* Select your newly installed codes from the Artemis list.
* Press **✖ (Cross)** on `Start` in the main menu.
* From the XMB, launch your game (or launch your homebrew to mount the game first).
* 
**4. Attaching the Cheats In-Game**
* When the game has launched, a notification will appear in the corner saying: `Artemis PS3 / Start to Attach`.
* Once you are ready to use your codes in the game, open the in-game XMB by pressing the **PS button** on your controller.
* **Hold the START button** until Artemis displays a notification saying that it has attached.
* At this point you can fully enjoy the patch.

**5. Detaching and Stopping**
* Enter the in-game XMB and **hold the SELECT button** if you wish to detach Artemis and stop the constant writing.
